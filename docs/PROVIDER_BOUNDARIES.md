# Provider Boundaries

## Federato

Server-only authentication, runtime schema discovery, and validated read-only queries. The browser never receives credentials or raw authentication responses. No mutation operation is supported.

## Baseten

Appetite compilation, schema mapping, query planning, one bounded repair, and short cited explanations. Every structured response is validated before use; deterministic fallbacks remain available.

## OpenAI

Interactive Senior Reviewer over narrow read-only tools. It may inspect packets, evidence, rules, comparisons, deterministic counterfactuals, appetite diffs, and broker-question drafts. It cannot change a packet, contact a broker, quote, bind, or decline.

## Deterministic application code

Owns evidence normalization, calculations, rule predicates, tier precedence, ranking, counterfactual outcomes, query validation, citation validation, and budget enforcement.
